# My Portfolio

A personal developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Deployment

This portfolio is configured for deployment to GitHub Pages using GitHub Actions.
